## 🎯 PURPOSE

`01_CURRENT_EXECUTION` contains the **actual short-term study and preparation plans** derived from the long-term Master Roadmap.

The Master Roadmap answers:

> **What should I learn, in what order, and why?**

The Current Execution system answers:

> **What exactly should I do today and this week?**

This folder therefore converts the strategic roadmap into **specific, dated, actionable work**.

# 🔄 ADAPTIVE SYSTEM

The Current Execution Plan is deliberately short-term and adaptive.

It should **not** be generated months in advance at maximum detail.

Actual progress matters.

If a topic takes longer than expected:

→ adjust the next execution batch.

If a topic is easier than expected:

→ use the available capacity for appropriate practice, revision or advancement.

If college becomes busy:

→ redistribute workload.

If gym days change:

→ redistribute daily workload.

If internship/placement requirements change:

→ update future execution batches while preserving the strategic priorities of the Master Roadmap.

# ⚖️ WORKLOAD PRINCIPLE

We will **not** schedule every day at maximum capacity.

Different days can have different workloads.

```text
Heavy college + gym day
        ↓
lighter study workload

Lighter day / Tuesday
        ↓
greater study capacity

Weekend
        ↓
deep work + revision + catch-up
```

The curriculum sequence remains stable.

The **amount of work assigned to a particular day** is what adapts.

---

# 🔁 WEEKLY CATCH-UP

Saturday and Sunday provide important flexibility.

If some work remains incomplete:

1. Complete essential unfinished work.
2. Complete important practice.
3. Perform scheduled revision.
4. Use remaining time for optional/stretch work.

The goal is:

> **Stay on track by the end of the week, rather than obsessing over perfect daily completion.**
