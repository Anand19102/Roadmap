# 10 — PYTHON / DATA / POWER BI SEQUENCE

> **Role:** Secondary career/portfolio track.
>
> **Primary stack remains:** Java → DSA → Spring Boot → Backend → Cloud/Distributed Systems.
>
> Python/Data/Power BI deliberately enters **after significant progress has been made in the primary stack**.

---

# 1. Strategic Position

The roadmap does **not** treat Python/Data as an alternative primary track during the initial preparation period.

The intended structure is:

```text
PRIMARY
Java
 ↓
DSA
 ↓
SQL
 ↓
Spring Boot
 ↓
Backend
 ↓
Projects
 ↓
Cloud / Distributed Systems

SECONDARY
Python
 ↓
NumPy
 ↓
Pandas
 ↓
Data Analysis
 ↓
Visualisation
 ↓
Power BI
 ↓
DAX
 ↓
PL-300-oriented preparation
 ↓
Data project
```

The secondary track exists to:

* broaden employability
* support data-oriented opportunities
* create an additional project
* provide Power BI capability
* preserve an optional future pivot into analytics/data roles

It must not derail the main placement preparation.

---

# 2. Mastery Classification

| Level                   | Meaning                                                               |
| ----------------------- | --------------------------------------------------------------------- |
| 🔴 MASTER               | Can independently use the skill to build and solve practical problems |
| 🟠 STRONG UNDERSTANDING | Can use it comfortably with occasional reference                      |
| 🟡 LEARN / USE          | Enough for practical project usage                                    |
| 🟢 SKIM                 | Understand the ecosystem and basic usage                              |
| ⚪ SKIP FOR NOW          | Deliberately postponed                                                |

---

# 3. Phase I — Python

## Python Fundamentals

Topics:

* syntax
* variables
* data types
* operators
* conditionals
* loops
* functions
* strings
* lists
* tuples
* sets
* dictionaries
* comprehensions
* modules
* exceptions
* file handling
* basic object-oriented concepts

### Classification

🟠 **STRONG UNDERSTANDING**

Python does not need the same depth as Java because Java is the primary DSA/backend language.

---

# 4. Python Practice

Focus on:

* writing small scripts
* manipulating lists/dictionaries
* reading files
* transforming data
* basic functions
* solving small data-oriented problems

Avoid duplicating the entire Java DSA curriculum in Python.

---

# 5. Phase II — NumPy

Topics:

* arrays
* dimensions
* shape
* indexing
* slicing
* vectorised operations
* aggregation
* basic numerical operations

### Classification

🟡 **LEARN / USE**

The objective is practical data manipulation.

---

# 6. Phase III — Pandas

This becomes the central Python/Data component.

Topics:

* Series
* DataFrame
* loading data
* inspecting datasets
* selecting rows/columns
* filtering
* sorting
* missing values
* cleaning
* transformations
* grouping
* aggregation
* merging
* joining
* reshaping
* exporting data

### Classification

🔴 **MASTER**

The goal is practical fluency.

---

# 7. Phase IV — Data Analysis

Learn a repeatable workflow:

```text
Business question
      ↓
Understand dataset
      ↓
Clean dataset
      ↓
Explore data
      ↓
Calculate metrics
      ↓
Identify patterns
      ↓
Visualise
      ↓
Communicate findings
```

### Classification

🔴 **MASTER**

This is more important than memorising individual Pandas commands.

---

# 8. Phase V — Data Visualization

Learn:

* appropriate chart selection
* distributions
* comparisons
* trends
* relationships
* categorical analysis
* basic statistical interpretation

Python visualization can be learned sufficiently for analysis projects rather than as a specialised visualisation career.

### Classification

🟠 **STRONG UNDERSTANDING**

---

Power BI enters after Python/data fundamentals.

* data modelling
* visualisations
* dashboards

* measures

* publishing/sharing concepts

for the practical dashboard/project level.

---

# 10. Phase VII — DAX

Topics:

* DAX fundamentals
* measures
* calculated columns
* aggregation
* filter context
* basic time intelligence

### Classification

The order is:

```text
Power BI fundamentals

Data transformation
```

# 13. Secondary Track Scheduling

Python/Data/Power BI should initially occupy a **small fraction of study time**.

Primary priority:

```text
Java / DSA / Backend
        >
SQL / Core CS
        >
Aptitude / Placement
        >
Python / Data / Power BI
```

This is not a permanent ranking of career value.

It is the priority for the current placement roadmap.

---

# 14. Semester Break Opportunity

The semester break is an ideal opportunity to increase time allocated to:

* Python
* Pandas
* Data Analysis
* Power BI
* PL-300
* data project

because regular classes and gym commitments are temporarily reduced.

The break therefore acts as an **acceleration window**, rather than forcing heavy Python study during the busiest semester period.

---

# 15. What NOT to Add

Do not unnecessarily expand this track into:

* advanced machine learning
* deep learning
* advanced statistics
* data engineering
* Spark
* complex cloud data platforms
* extensive Python DSA

unless a later internship/placement opportunity specifically makes them relevant.
