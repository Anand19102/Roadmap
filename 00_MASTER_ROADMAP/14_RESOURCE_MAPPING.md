# 🗺️ MASTER RESOURCE MAPPING

> **Purpose:** Define how every major resource contributes to the roadmap and prevent duplicate learning.
>
> The roadmap does **not** treat every playlist, book or course as something that must be completed from beginning to end.

# 2. TELUSKO

## Primary role

**Java language foundation + advanced Java ecosystem foundation.**

Telusko is not treated as a course that must be watched indiscriminately.

Every topic is classified using:

```text
🔴 MASTER
🟠 STRONG UNDERSTANDING
🟡 LEARN / USE
🟢 SKIM
⚪ SKIP FOR NOW
```

See:

`02_KEEP_IN_MIND/01_MASTERY_CLASSIFICATION_SYSTEM.md`

---

## Telusko → Java

Primary purpose:

* understand Java syntax
* understand Java execution model
* build language fluency
* learn object-oriented programming
* understand collections
* understand exceptions
* understand useful Java features
* prepare the language foundation required for DSA and backend

12. Trees / Traversals
13. DFS
14. BFS

17. Topological Sort / Kahn's Algorithm
18. Trie
19. Greedy
20. Dynamic Programming
21. Minimum Path Sum

23. Bitwise Operations

These are **mapped into the DSA progression**, not necessarily watched in this raw numerical order.

# 14. AI TOOLS

AI is treated as an engineering tool rather than a substitute for learning.

Permitted uses include:

* explaining concepts
* debugging
* reviewing code
* generating test cases
* brainstorming
* documentation assistance
* code review
* learning unfamiliar APIs

Not acceptable:

* copying complete solutions blindly
* submitting code that cannot be explained
* using AI to bypass DSA practice
* claiming AI-generated implementation as personal understanding

See:

`02_KEEP_IN_MIND/16_AI_USAGE_RULES.md`

# 17. RESOURCE COMPLETION RULE

Completion does **not** mean:

> Watched every minute.

Completion means:

> Acquired the required level of understanding, practiced it sufficiently, and can use/explain it at the required depth.

Therefore:

```text
100% of a resource
≠
100% of required learning
```

and:

```text
60% of a resource deeply understood
>
100% passively watched
```

# 19. FINAL RULE

No resource is allowed to become the roadmap.

**The roadmap decides what needs to be learned.**

Resources are tools used to achieve that learning objective.

```text
CAREER GOAL
     ↓
ROADMAP
     ↓
REQUIRED KNOWLEDGE
     ↓
RESOURCE
     ↓
PRACTICE
     ↓
PROJECT / PROBLEM
     ↓
REVISION
     ↓
INTERVIEW READINESS
```

This prevents the preparation from becoming:

```text
playlist completion
book completion
certificate collection
```

and keeps it focused on:

```text
actual competence
+
problem solving
+
engineering ability
+
interview readiness
+
evidence of ability
```
