# 6. THE FIVE-TIER MASTERY SYSTEM

Every important topic in this roadmap receives a mastery classification.

| Level                   | Meaning                                                                          |
| ----------------------- | -------------------------------------------------------------------------------- |
| 🟥 MASTER               | Deep understanding + implementation + repeated practice + interview readiness    |
| 🟧 STRONG UNDERSTANDING | Understand thoroughly and be able to use/explain it; less repetition than Master |
| 🟨 LEARN / USE          | Learn enough to implement/use correctly; do not over-invest                      |
| 🟩 SKIM                 | Understand the purpose and basic idea; move on quickly                           |
| ⚪ SKIP FOR NOW          | Deliberately postpone; not currently worth the opportunity cost                  |

The classification is **not a statement about whether a topic is important in general**.

It is a statement about:

> **How deeply YOU need to learn that topic at THIS stage of YOUR career roadmap.**

The detailed operational rules live in:

`02_KEEP_IN_MIND/01_MASTERY_CLASSIFICATION_SYSTEM.md`

# 9. PROBLEM-SOLVING SYSTEM

DSA preparation will follow a fixed protocol rather than random question solving.

Every serious problem follows:

```text
1. Understand the problem
2. Identify input/output
3. Clarify constraints
4. Build brute force
5. Analyze complexity
6. Search for patterns
7. Choose optimized approach
8. Dry run
9. Implement
10. Test edge cases
11. Analyze complexity again
12. Explain the solution aloud
13. Record mistakes if necessary
14. Revisit during revision
```

The complete protocol is stored in:

`02_KEEP_IN_MIND/02_PROBLEM_SOLVING_PROTOCOL.md`

# 22. FINAL OBJECTIVE

By graduation, the goal is not simply:

> "I completed Telusko."

or:

> "I solved 300 LeetCode questions."

or:

> "I know Spring Boot."

The objective is:

> **Become a genuinely employable software engineer with strong Java/DSA foundations, practical backend development ability, solid CS fundamentals, strong interview preparation, meaningful projects, and enough breadth to adapt as the industry changes.**

The roadmap therefore prioritizes **depth, sequencing, repetition, application and employability over course completion.**
