# 🥇 RESOURCE PRIORITY

## Tier 1 — Primary learning resources

### 1. Telusko

Use Telusko as the main guided learning resource wherever the course covers
Spring / Spring Boot / backend concepts relevant to our roadmap.

Telusko is especially useful for:

- guided explanations
- seeing concepts implemented
- understanding the Java-to-Spring transition
- learning the practical development workflow

---

### 2. Official Spring Documentation

Official documentation is the long-term reference source.

Use it for:

- exact API behaviour
- configuration
- annotations
- Spring concepts
- Spring Boot features
- official examples
- production-oriented understanding
- checking version-specific behaviour

Official Spring Boot documentation:

https://docs.spring.io/spring-boot/

Official Spring Framework documentation:

https://docs.spring.io/spring-framework/reference/

Spring Boot documentation is organized around first steps, application
development, web, data, messaging, production and advanced topics. :contentReference[oaicite:0]{index=0}

### 3. Spring Guides

Use Spring's official Getting Started guides when we need a focused,
implementation-oriented explanation.

Primary guide:

https://spring.io/guides/gs/spring-boot/

The official guide demonstrates creating a Spring Boot application and using
Spring Initializr. :contentReference[oaicite:1]{index=1}

# 🥈 SECONDARY RESOURCES

## Spring Quickstart

Use for:

- first Spring Boot application
- project initialization
- understanding basic application structure
- getting comfortable with the ecosystem

Spring's Quickstart currently recommends an IDE such as IntelliJ IDEA,
VS Code with Spring extensions, or Eclipse, and recommends a JDK such as
17 or 21 for the guide. :contentReference[oaicite:2]{index=2}

- Transactions

# 🚫 WHAT WE WILL NOT DO

We will NOT:

- collect multiple Spring Boot courses
- watch several instructors explain the same annotation
- memorize every Spring annotation
- read the entire Spring documentation
- learn microservices before understanding monolithic REST applications
- jump into Spring Security before understanding HTTP/API fundamentals
- blindly copy tutorial projects

# ⚠️ VERSION RULE

Spring Boot and Spring Framework evolve.

Therefore:

> **Do not memorize version-specific behaviour from old tutorials.**

When a tutorial and official documentation disagree:

**Official documentation wins.**

The roadmap will also pin the relevant Spring Boot version when a project
is actually created.
