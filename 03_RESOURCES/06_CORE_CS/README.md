# 1️⃣ OBJECT-ORIENTED PROGRAMMING

## Primary resource

### Java / Telusko

OOP should initially be learned through Java itself.

Focus on:

- Classes
- Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- Composition
- Method overriding
- Method overloading
- Access modifiers

---

## Official reference

Use Dev.java when Java language behaviour needs verification.

Dev.java's learning material includes classes, objects, interfaces,
inheritance and generics. :contentReference[oaicite:3]{index=3}

---

## Study rule

Do not learn OOP as definitions alone.

For every major concept:

**Understand → implement → explain → compare → use**

Example:

Do not merely memorize:

> "Polymorphism means one interface, many implementations."

You should be able to demonstrate:

- method overloading
- method overriding
- dynamic dispatch
- interface-based programming

# 🚫 WHAT WE WILL NOT DO

We will not:

- memorize giant lists of interview answers
- watch multiple complete OS courses
- watch multiple complete CN courses
- learn distributed systems before backend fundamentals
- start system design too early
- treat Core CS as a separate isolated universe

---

# 🧠 CORE CS LEARNING MODEL

Every topic should eventually reach four levels:

### Level 1 — Understand

What is it?

### Level 2 — Explain

Can I explain it without notes?

### Level 3 — Apply

Can I recognize it in code/system behaviour?

### Level 4 — Interview

Can I answer common interview questions and comparisons?
