# 2. HOW WE USE TELUSKO

Telusko is divided into five mastery levels according to the roadmap's global classification system.

| Level                   | Meaning                          | Telusko action                                     |
| ----------------------- | -------------------------------- | -------------------------------------------------- |
| 🔴 MASTER               | Core career/interview competency | Learn deeply + code + revise + explain             |
| 🟠 STRONG UNDERSTANDING | Important supporting competency  | Understand thoroughly + implement when appropriate |
| 🟡 LEARN / USE          | Useful practical knowledge       | Learn enough to use confidently                    |
| 🟢 SKIM                 | Awareness / context              | Watch once or selectively                          |
| ⚪ SKIP FOR NOW          | Not currently worth time         | Do not study unless roadmap later activates it     |

**Important:** these classifications are **roadmap classifications**, not judgments that the course material itself is unimportant.

A topic can be valuable professionally while still being lower priority for the current placement goal.

# 7. THREE-TIER LEARNING RULE

For important Telusko topics:

### Tier 1 — Understand

Watch the lesson and understand the concept.

### Tier 2 — Implement

Close the video.

Write your own code.

### Tier 3 — Recall

Later, without the video:

* explain the concept
* reproduce important syntax
* solve a small problem
* answer interview questions
