# ✍️ APTITUDE NOTE SYSTEM

For each topic maintain:

### 1. Formula sheet

Only formulas that genuinely need memorization.

### 2. Shortcut sheet

Only shortcuts that you can reproduce reliably.

### 3. Pattern sheet

Recognize:

> "When I see this question structure, I should think of this method."

### 4. Mistake log

Record:

- calculation errors
- concept errors
- wrong method
- time-management errors

---
