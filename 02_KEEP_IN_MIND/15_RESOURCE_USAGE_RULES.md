# 📚 RESOURCE USAGE RULES
## How to Use Courses, Playlists, Books, Documentation & Practice Sources

---

## 1. PURPOSE & PRIMARY PRINCIPLE

The roadmap uses multiple resources. They are NOT competing courses. Each resource has a defined purpose.

> **One concept → one primary learning source → practice → supplementary source only when necessary.**
Avoid consuming five explanations of the same beginner concept.

---

## 2. RESOURCE HIERARCHY

```text
Primary Course → Official Documentation → Practice → Supplementary Explanation → Advanced Reference
```

---

## 3. RESOURCE DEFINITIONS

* **TELUSKO:** Java foundation → modern Java → backend/Spring ecosystem where applicable.
* **KUNAL KUSHWAHA:** Java + DSA conceptual foundation and implementation practice.
* **ITSRUNTYM:** Pattern recognition. Used to answer: *"How do I recognize which technique this problem is asking for?"*
* **NEETCODE:** Curated problem practice and pattern reinforcement. Use after the prerequisite concept has been learned.
* **OFFICIAL DOCUMENTATION:** Use for learning APIs, checking exact behavior, verifying syntax. Should become increasingly important as skill increases.
* **YOUTUBE:** Alternative explanations, visual explanations, difficult concepts. Avoid endless recommendation loops.
* **BOOKS:** Deeper reference, structured aptitude preparation, difficult theory.
* **PRACTICE PLATFORMS:** (LeetCode, HackerRank, DataLemur) Use to convert learning into skill.

---

## 4. RESOURCE SWITCHING RULE

Switch resources only when:
A. The current resource genuinely fails to explain the concept.
B. The roadmap explicitly assigns another resource.
C. I need an alternative explanation.
D. The topic is outside the scope of the current resource.

Do not switch because: *"Another playlist looks more interesting."*

---

## 5. THE 80/20 RULE

Most topics should have: Primary source + practice.
Not: 5 courses + 3 playlists + 10 articles.

---

## 6. COMPLETION DOES NOT MEAN WATCHING

A resource is "completed" only when:
`Watched/read + understood + implemented + practiced + revised` (depending on the topic).

---

## 7. GOLDEN RULE

Resources are tools. The skill is the destination. Never confuse resource consumption with progress.
