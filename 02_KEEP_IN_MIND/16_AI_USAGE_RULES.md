# 🤖 AI USAGE RULES
## Responsible Use of GPT, Coding Assistants & AI Agents

---

## 1. PURPOSE

AI is allowed and encouraged as a learning and engineering tool. However:
> **AI must increase my capability, not replace it.**

---

## 2. AI SHOULD HELP ME

AI can help with: explanations, debugging, alternative approaches, code review, test-case generation, documentation, brainstorming, architecture discussion, interview simulation, project feedback, learning plans, error interpretation.

---

## 3. AI MUST NOT REPLACE

AI must not replace my ability to:
- solve DSA problems
- understand Java
- design basic systems
- write SQL
- debug
- explain projects
- reason about code
- answer interview questions

---

## 4. DSA AI RULE

When solving a DSA problem:
1. Attempt independently.
2. Use AI for: hint, identifying conceptual mistake, complexity discussion, edge cases.
3. Only later request the full solution if genuinely necessary.

If AI gives the solution: **Re-code it independently afterward.**

---

## 5. PROJECT AI RULE

AI may help generate boilerplate, test cases, documentation drafts, configuration, repetitive code.
But I must understand the resulting code. For important architectural decisions: I should be able to explain why the code exists.

---

## 6. DEBUGGING RULE

Preferred order:
```text
Read error → Think → Inspect code → Search documentation → Ask AI
```
When asking AI: Provide the exact error and relevant context. Avoid: *"My code doesn't work. Fix everything."*

---

## 7. AI AS TEACHER & INTERVIEWER

* **Teacher prompt structure:** "I am learning X. I currently understand A, B and C. I am confused about D. Explain D using: 1. intuition 2. simple example 3. code 4. common mistakes 5. interview relevance"
* **Interviewer:** Eventually use AI for DSA, Java, backend, SQL, Core CS, and project interviews.

---

## 8. THE "CAN I EXPLAIN IT?" TEST

Before retaining AI-generated material: Can I explain this without AI? If not: Learn it first. Never blindly trust generated code. Check correctness, security, edge cases.

---

## 9. THE "AI DEPENDENCY" WARNING SIGNS

Warning signs:
- unable to code without AI
- asking AI before thinking
- accepting every suggestion
- inability to debug independently
- copying generated DSA solutions
- building projects entirely through prompts

If these appear: Reduce AI assistance temporarily.

---

## 10. GOLDEN RULE

AI is my copilot, not my brain.
